## Using the corpus

```bash
grep -rn "tool poisoning" fulltexts/          # search every transcript
grep -l "PyQGIS" fulltexts/*.md               # which papers mention a term
sed -n '1,20p' fulltexts/hou2025mcp.md        # frontmatter + first page
```

The 27 GIScience-canon entries (stream F: standards, data quality, cartography, VGI, FOSS-GIS,
reproducibility) are **bibliographic only** — no transcripts, by design: they are cited for concept and
convention, not for empirical claims about agents. Book rows link to OpenLibrary, standard rows to the
publisher of record (ISO) or `docs.ogc.org`.

Transcription is `pdftotext` without `-layout` (correct reading order for two-column papers):
running prose and references survive, but **table columns are scrambled and figures, equations
and footnotes are lost**. Quote from the published PDF, never from a transcript.

## Citing

`literature.bib` is plain biblatex; cite with `\cite{key}`. It contains **no custom fields** —
the six provenance attributes this project used to carry (`record-source`, `retrieved`,
`confidence`, `abstract-source`, `oa-status`, `license`) needed a `.dbx` datamodel, so they now
sit as one `% provenance [key]: …` comment line above each entry. Legal BibTeX, invisible to
biber, still greppable:

```bash
grep "provenance \[hou2025mcp\]" literature.bib
```
